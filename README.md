# CEIP Toxiria · Plan de Centro 2026/27

Web de consulta del Plan de Centro del CEIP “Toxiria” de Torredonjimeno.

## Publicar con GitHub Pages

1. Crea un repositorio nuevo en GitHub, por ejemplo:
   `ceip-toxiria-plan-centro-2026-27`
2. Sube **index.html** a la raíz del repositorio.
3. En GitHub entra en **Settings → Pages**.
4. En **Build and deployment**, selecciona:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Guarda los cambios.
6. GitHub generará la dirección de la web, normalmente:
   `https://TU-USUARIO.github.io/ceip-toxiria-plan-centro-2026-27/`

## Características

- Diseño responsive para ordenador, tablet y móvil.
- Buscador de contenidos.
- Filtros por categorías.
- Apartados desplegables.
- Botón de impresión.
- El contenido está integrado en un único `index.html`, por lo que no necesita servidor ni base de datos.
